## Soak

900 s at concurrency 16, mixed providers, a third streamed, task outcomes posted: **147972 ok, 0 errors**. Ledger 147972 rows, 37.52 MB (266 bytes/request); `prefixwise report` on it: 0.39 s. RSS 59.5 MB warm -> 73.9 MB at the end; threads 1, fds 7.

## Notes

- Before the fixes in this PR the same machine measured +50 ms p50 added latency at 120k tokens (81% of it in `mask_volatiles`), and the idle-connection case held 301 threads indefinitely.
- Soak RSS 59.5 -> 73.9 MB over 900 s. A tracemalloc run of the same traffic in-process shows Python-level memory flat once the session map and the masked-hash cache are full (16.2 MB at 2,400 and at 4,800 sessions), so the RSS drift is the allocator retaining freed request buffers, not a leak.
- Ledger: 1M synthetic rows (138 MB): `prefixwise report` 2.2 s, `fixes` 2.3 s.
