**What this shows**

- **The engine join works on a real GPU (A2).** The session's prefix covers about 213 KV
  blocks (3,404 tokens / 16); vLLM's events showed 211 of them removed, and Prefixwise named
  the miss a confirmed eviction from that evidence. Without events (A1) the same miss is an
  inferred eviction, as designed.
- **LMCache turns the eviction into a hit (B1, B2):** 98% of the prefix came back from CPU
  memory after the GPU copy was evicted, and Prefixwise counted it as a hit. vLLM's
  `cached_tokens` includes LMCache's tokens, as read in its source.
- **SGLang (C1, C2):** the classifier is 120/120 on SGLang, and an eviction there is named
  (inferred; SGLang's events cannot be attributed to sessions).
- Before the engine join, A1/A2/C2 would have been reported as `routing_miss`.
