# Gateways round 3: Plano on the fixed code, Bifrost with a virtual key (2026-11-24)

Muse ran this in Colab on a fresh runtime, with no API keys and no spend, and it took 25 minutes. Code:
`1566bc7f` (main, with the chunked-body fix from round 2). The setup is as in [round 1](2026-11-24-round1.md) and
[round 2](2026-11-24-round2.md):
- each gateway's OpenAI and Anthropic upstream was `prefixwise serve` on port 4100;
- the cache mock sat behind it on port 4101;
- each check sent 5 five-turn conversations per format: one unchanged, and four with one change at turn 3.

The result files are in [`2026-11-24-round3/`](2026-11-24-round3/), taken from the appendix of Muse's PDF report.
Every total was recomputed from the per-conversation results.
- `capture.jsonl` is the capture proxy's log: how each request reached it, never the text. It was rebuilt from
  the PDF, where its lines were wrapped.
- The ledger was not sent. Muse reports 451 rows: the 450 calls below, plus one probe request.

## What it shows

- **The chunked-body fix works behind Plano.** Every Plano check from round 2 that was rerun now passes (OpenAI,
  Anthropic, OpenAI streamed), and so does Anthropic streamed, new this round. Round 2's runs with
  provider-prefixed model names were not repeated.
- **Plano sends its request bodies chunked.** All 50 checker requests (not streamed: the capture run did not stream) reached the capture proxy with
  `Transfer-Encoding: chunked` and no `Content-Length`: 25 to `/v1/chat/completions` and 25 to `/v1/messages`.
  The Anthropic ones kept their `cache_control` markers. This confirms directly what round 2 inferred from the
  matching verdicts.
- **Bifrost works with Prefixwise as its upstream**: with a virtual key, streamed and not; with key enforcement off,
  not streamed.
  - Bifrost did not pass Prefixwise's own session header, or `x-session-id`. The conversation id reached
    Prefixwise through the request body.
  - Prefixwise falls back to the body's `user` (OpenAI) or `metadata.user_id` (Anthropic) when no session header
    arrives.
  - Bifrost's forwarded-header form `x-bf-eh-x-prefixwise-session-id` also gets the id through.
  - A client behind Bifrost should send either one. Without them, Prefixwise has no conversation to compare
    against.

Every run used the cache mock, not a real provider.
